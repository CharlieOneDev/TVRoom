# Security · セキュリティ · 安全说明

**English:** Do not disclose exploitable vulnerabilities, credentials, or personal data in public issues. If the repository offers GitHub private vulnerability reporting, use Security → Report a vulnerability. Otherwise ask the maintainer for a private contact without posting sensitive details. No response-time or supported-version guarantee is currently offered. External video and embedded websites are third-party services; never enter secrets into an untrusted embedded page.

**日本語:** 脆弱性の悪用手順、認証情報、個人情報を公開 Issue に投稿しないでください。GitHub の非公開報告が有効なら Security → Report a vulnerability を使い、それ以外は機密情報を書かずに管理者へ非公開の連絡方法を確認してください。対応時間やサポート対象バージョンの保証はありません。信頼できない埋め込みページには秘密情報を入力しないでください。

**简体中文：** 不要在公开 Issue 披露可利用的漏洞细节、密钥或个人信息。如仓库启用了 GitHub 私密漏洞报告，请使用 Security → Report a vulnerability；否则先向维护者询问私下联系方式，不要附敏感细节。目前不承诺响应时限或受支持版本。不要在不可信的嵌入网页中输入秘密信息。
